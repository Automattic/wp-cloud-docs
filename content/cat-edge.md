# Edge

Configure request and response behavior with [Edge Rules](/docs/edge/edge-rules/). For cached delivery, use [Edge Cache](/docs/performance/cache/edge-cache/), [Edge Cache preload](/docs/performance/cache/edge-cache-preload/), and [Woo cart caching](/docs/performance/cache/woo-cart-caching/). [Image transformation](/docs/performance/image-optimization/image-transformation/) resizes and transforms uploaded images at the edge. Use [edge request logs](/docs/monitoring-logs/logs/edge-request-logs/) to investigate traffic, and [origin and edge servers](/docs/infrastructure/origin-edge-servers/) to understand the infrastructure.
