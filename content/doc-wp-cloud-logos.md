# WP Cloud logos

Partners that co-market WP Cloud can download the current WP Cloud logos and
banners from the [WP Cloud press kit](https://wp.cloud/inquiries/#download).
The press kit is the current source for available file and layout options.

| Asset | Purpose | Example |
| --- | --- | --- |
| WP Cloud logo and wordmark | Identifies WP Cloud in partner or press material. | A technology-partner section on a hosting product page. |
| Press-kit banners | Supports approved announcements and editorial coverage. | A co-marketing launch post. |

Use the supplied files without redrawing, stretching, recoloring, or changing
the relationship between the mark and wordmark. Coordinate prominent campaign,
event, or co-branded uses with the WP Cloud team so both organizations can use
the correct current assets.

Partners that do not show WP Cloud branding can instead [white label the
service](/docs/partner-resources/branding-marketing/white-labelling/).
