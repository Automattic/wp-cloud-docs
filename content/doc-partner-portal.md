# WP Cloud Partner Portal

The [WP Cloud Partner Portal](https://hosts.automattic.com/wpcloud) is the
authenticated account area for WP Cloud partners. Use it to review account and
site information, inspect metrics in Insights, manage the account features
available to you, contact support, and view the documents accepted for the
partnership.

## Portal sections

The sections you can open depend on your account access.

### Account overview and partnership details

The account overview summarizes the WP Cloud account. Partnership Details
shows the information recorded for the partnership.

### Insights

Insights provides metrics and statistics for the partner's entire WP Cloud
account and for individual sites. The AI assistant in Insights can help you
inspect this data.

### Inventory

Inventory lists the sites associated with the partner account. Use it to find
a site's stable WP Cloud site ID when working with the API or investigating a
site-specific platform problem.

### API keys and billing

API key management and billing management are restricted areas. Only users
with access to these areas can manage API keys or billing information in the
portal. Other portal users do not automatically receive access to them.

Treat API keys as credentials. Do not share them in tickets, chat messages, or
team documentation. See the [WP Cloud API quick
start](/docs/api-automation/api-quick-start/) for API access and credential
requirements.

### Team management

Team management lets partners invite additional users. Invited users can
review the site inventory and Insights without sharing another person's login.
Access to API key management and billing remains restricted.

Remove access when a person no longer needs it. Give each person an individual
account instead of sharing a general team login.

### Support requests

Use Support request to contact WP Cloud Support about a platform issue. [Get
support](/docs/getting-started/get-support/) explains what WP Cloud Support
covers and what information to include.

### Accepted documents

The portal provides access to the documents accepted for the partnership:

- Terms of Service;
- Data Processing Addendum;
- Automattic Privacy Policy; and
- WP Cloud Site Meta Billing Policy.

## Continue setup

Use [Key onboarding steps](/docs/getting-started/onboard-launch/) for the
work that takes a partner from evaluation through launch. When API keys are
available, use the [WP Cloud API quick
start](/docs/api-automation/api-quick-start/) to test access and begin working
with sites.
