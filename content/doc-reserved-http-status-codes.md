# WP Cloud HTTP status codes

WP Cloud uses several HTTP status codes for platform suspension, security, and
rate-limiting responses. Platform responses can take precedence over a custom
WordPress error template that uses the same code.

The tables below describe the WP Cloud meaning of each value. They do not
replace the standard HTTP specification for responses generated by site code.

## Site suspension and maintenance

The `suspended` [site meta](/docs/sites/site-meta/) value controls the response
used for a host-partner suspension.

| Status Code | WP Cloud behavior |
| --- | --- |
| `402` | Reserved for platform-level use. |
| `480` | Default soft suspension. HTTP requests are blocked while User SSH and Client SSH remain available. |
| `403`, `404`, `410`, or `451` | May be selected for a host-partner suspension. User SSH is blocked; Client SSH remains available. |
| `503` | May be used for maintenance, site locking, and workflows such as an in-place backup restore. |

HTTP 404 is not otherwise reserved, although WP Cloud can return it for a
suspended site or for a missing static file when [lightweight
404s](/docs/performance/lightweight-404s-static-files/) are enabled.

In this context, a suspension code means that the platform is controlling the
response before WordPress handles the request; it does not describe an error
generated by the site's application code.

## Security, rate limiting, and performance

| Status Code | Common WP Cloud use |
| --- | --- |
| `403` | A request is forbidden by a security or access control. |
| `406` | The web application firewall rejected the request. |
| `428` | A platform security or request-control response. |
| `429` | The request was rate limited. |
| `599` | WP Cloud limited a request because the site exhausted available PHP capacity. The public response may appear as HTTP 429. |

See [Rate limiting](/docs/security/traffic-protection/rate-limiting/), [Network and web application
firewalls](/docs/security/traffic-protection/firewalls/), and [Troubleshoot HTTP 429 and 599
errors](/docs/troubleshooting/429-599-errors/) before assigning a custom
meaning to these codes.
