# White labelling and co-marketing WP Cloud

WP Cloud host partners can present their hosting service under their own brand,
co-market the WP Cloud platform, or combine the two approaches. WP Cloud
operates below the partner's product and API layer, so end users do not need to
see WP Cloud branding unless the partner chooses to show it.

## White label the service

White labelling keeps the customer relationship, product name, pricing,
control panel, documentation, and support experience under the host partner's
brand. It is useful when a partner wants one consistent identity across its
services or does not want infrastructure vendors to complicate customer
messaging.

## Co-market with WP Cloud

Co-marketing lets a partner explain that WP Cloud powers its WordPress hosting
infrastructure. Partners can use approved WP Cloud brand assets and may work
with the WP Cloud team on case studies, event sponsorships, podcasts, and other
joint marketing opportunities.

Use the current assets on [WP Cloud logos](/docs/partner-resources/branding-marketing/wp-cloud-logos/)
and coordinate material brand uses with the WP Cloud team.
